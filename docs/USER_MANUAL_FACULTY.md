# Faculty User Manual — ECE Department Smart Portal

This guide covers day-to-day use of the portal for faculty accounts.

## Sign in

1. Open the portal URL provided by the department.
2. Sign in with your **portal email and password** (not necessarily your Gmail/Outlook password unless admin configured it that way).
3. On first login you may be asked to change your password under **Profile**.

If you forget your password, use **Forgot password?** on the login page. A temporary password is emailed when SMTP is enabled.

## What you can see

Your account is linked to a **faculty directory record** (`faculty_id`). That link — not your email spelling or display name — controls which projects, courses, publications, and similar records you see. If something looks empty, ask an admin to confirm your account is linked to the correct faculty entry.

## Top navigation

| Tab | Purpose |
|-----|---------|
| **Dashboard** | Overview / entry point |
| **Feedback** | Send feedback to admins; see resolved status |
| **CO-PO Attainment** | Generate / compare / bulk CO-PO evaluations |
| **Publications** | Faculty directory, search, student publications, exports |
| **Projects and Theses** | Your guided projects, SDG review |
| **Budget** | Accumulated income, expenditure, inventory (as permitted) |
| **Course Allocation** | Your teaching allocations (faculty-wise / course-wise) |
| **Minutes** | Meeting documents |
| **Analytics / Awards / Contributions** | Department analytics and your awards/contributions |
| **LLM Insights** | AI insights where enabled |
| **Notifications** | Messages from admins; reply and mark requirements done |
| **Moderation / Labs** | Question papers / lab seating (as permitted) |
| **Profile** | Password and account details |

## Feedback

1. Open **Feedback**.
2. Write your message and submit.
3. Admins (and HoD, by email when SMTP is on) are notified.
4. Your list shows whether each item is **Resolved** or **Unresolved**.

## Notifications

1. Open **Notifications** to read department requests.
2. Opening a message may update the Requirement Tracker (yellow = read).
3. Reply with text/attachments when asked.
4. Completing the requested work (or admin marking fulfilled) turns the tracker cell green.

## Projects and Theses

- Columns open with **Serial Number, Semester, Title, Guide, Actions**, then remaining fields.
- Review / accept SDGs from **Actions** (or Edit SDGs when LLM is off).
- Exports keep the previous column order for Excel compatibility.

## Course allocation

- Browse faculty-wise or course-wise views for your linked teaching history.
- **UG** and **PG** columns show the type (Core / Elective) at each level.
- **No. of registered students** is maintained by admins only; faculty cannot edit it.
- Course Catalog is admin-only.

## CO-PO

Use **CO-PO Generator** to upload consolidated marks, map COs/POs, and download attainment reports. Compare and Bulk flows are under the same menu group.

## Publications

Browse the faculty directory, open your profile, search publications, and use exports as permitted. Student publications are under the Publications group.

## Profile

Change your portal password any time. Keep the temporary password private until changed.
